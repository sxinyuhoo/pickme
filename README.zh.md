# Pick Me

在阅读 Markdown 与 PDF 时就地选中或框选内容提问与批注，不用跳页面。

[English](README.md) | **中文**

框完选题或在面板里直接问，答案与选区一起存成独立的批注文件，原文一字不动。

在 PDF 上有两种标注方式，工具栏里切换：拖**矩形**框住一块区域（区域里的文字与截图一起送给模型），或者拖**荧光笔**划过文字——笔画会自动吸附到文字行并渲染成干净的行带，手抖也不影响。两者的分工是明确的：**荧光笔只负责高亮**，划完就停在行带上、不弹提问面板（想就这段提问，点一下这条高亮即可）；**框选**划完则立刻弹出提问面板。当前用的是哪种，看工具栏上哪个图标带底色，也看鼠标指针——框选是十字，荧光笔是笔刷。同一条批注上两种可以叠加。

在 PDF 上拖一个矩形，区域里的文字与截图一起送给模型，框留在页面上，以后点它就能重新打开：

![自带 pdf.js 阅读器与目录](docs/screenshots/05-pdf-viewer-outline.png)

## 安装

- **社区插件**（上架后）：设置 → 第三方插件 → 浏览 → 搜 *Pick Me* → 安装 → 启用。
- **BRAT**（上架前的内测版）：先装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件，在它的设置里 Add beta plugin 填 `<你的 GitHub 用户名>/pickme`，之后一键更新。
- **手动**：把 `main.js`、`manifest.json`、`styles.css` 放进 `<库>/.obsidian/plugins/pickme/`，重启 Obsidian 后在设置里启用。仓库发版时会把这几个文件挂在 GitHub Release 上，直接下即可。
- 桌面端插件（`isDesktopOnly`），移动端用不了。

## 网络与隐私

这个插件**不收集任何数据、不做遥测**，但它需要联网调用你自己配置的模型接口：

- 你在设置里填的**接口地址**（OpenAI 兼容）就是唯一的网络出口。选中/框选的内容（文字、以及可选的区域截图）会发到那个地址，用于生成回答。用哪家、数据怎么处理，取决于你填的服务商。
- **API 密钥**保存在本库的 `.obsidian/plugins/pickme/data.json` 里，明文存储，和 Obsidian 其他插件一样。插件不会把它发往你配置的地址以外的任何地方。
- 默认不联网也能用一部分功能：批注、锚点、视觉标记、索引笔记都是纯本地操作。只有你主动提问时才把选区（以及可选的上下文；模板里写了 `pickme_include_note` 时还有整篇笔记）发出去。
- PDF 的 CMap 与标准字体**内联在 `main.js` 里**，不需要联网下载任何资源。
- 插件只在自己库内写文件（默认 `.obsidian/plugins/pickme/`：批注文件、模板、生成的索引），**不读取库外文件**。

## 授权与第三方组件

- 本插件：MIT，见 [LICENSE](./LICENSE)。
- 内置 [pdf.js](https://github.com/mozilla/pdf.js)（`pdfjs-dist@4.10.38`，Apache-2.0）用于 PDF 渲染，其 CMap 与标准字体由 `scripts/inline-pdf-assets.mjs` 内联进产物。
- pdf.js 里有用于字体渲染的 `new Function` 代码路径，本插件显式关闭（`src/pdf/pdfjs.ts` 的 `isEvalSupported: false`），运行期不会执行任何动态生成的代码；自动审查仍会提示「动态代码执行」，因为这段代码确实存在于产物里。

## 怎么用

交互都在页面上完成，侧边栏只用来查看已有批注，日常不必打开。

Markdown：

1. 选中一段文字 → 右键选 `Pick Me：提问或批注`（或命令面板搜「对选区提问或批注」）。
2. 插件在选区首尾各插一个带 id 的空标签，选区内文字与格式一个字节都不动。
3. 选区旁就地弹出提问面板：选模板或直接提问；对同一条批注再问就是追问，历史问答会一起送给模型。
4. 之后点正文里的高亮文字，面板就在那一页重新打开。

PDF：

1. 默认由 Pick Me 的 pdf.js 查看器接管 PDF 打开（设置里可关）。
2. 拖动鼠标框选一块区域（批注一律靠框选；只点一下不建批注）。
3. 抬手即完成批注，并在同一位置弹出提问面板；区域截图作为图片一起送给模型。
4. 点页面上已有的批注框，打开该条批注的面板并带出历史问答。
5. 面板用右上角 × 或 Esc 关闭。刚框出来、一个问题都没问过的批注，关掉面板就撤销（页面上的框一并收掉）；问过的会留着。
6. 工具栏按功能从左到右分四组，中间用细线隔开：**目录**（有书签才出现）｜**翻页**（上一页 / 页码框 / 总页数 / 下一页）｜**缩放**（缩小 / 百分比 / 放大 / 适应宽度，百分比按钮点一下回到 100%）｜**显示**（高亮开关：关掉就是干净的 PDF，页面上一条框都不画）。工具栏上的按钮只摆图标，鼠标停上去有说明；最右侧那行浅灰小字是当前状态，窄了会自动缩成省略号。
7. 面板右下角的「删除」要**问过之后**才出现——刚框出来还没提问的批注不摆删除，因为它关掉面板就等于撤销。删掉时页面上的框一起收掉（会先确认）。

**所有页竖着排在一根滚动条里**，和系统自带的 PDF 阅读器一样——滚动条长度代表整篇文档，页码框跟着滚动位置走。

| 方式 | 操作 |
| --- | --- |
| 滚轮 / 触控板 | 直接滚，连续往下看；PageUp / PageDown / Home / End 也是原生滚动 |
| 按钮 / 页码框 | 工具栏「上一页 / 下一页」整页跳，或在页码框里输页码回车 |
| 触控板横向滑动 | 左右滑一下整页跳（一次滑够约 120px 才生效，不会误触） |
| 键盘 | ← / → 整页跳（焦点在页码框里时不抢键；放大到要横向滚动时留给原生滚动） |

只渲染视口附近的页，离远了会把画布释放掉、滚回来再画——所以一百页的 PDF 也不会一次吃掉几百 MB 内存。

**目录（大纲）**：PDF 自带书签的（一般是排版规范的标准、手册、说明书）左侧会出现目录面板，点一条就跳到那一页。没书签的 PDF 不显示目录，也不摆这个按钮（空面板比没有更让人困惑）。目录开关随手一关就记住，下次打开还是这个状态。

## 批注索引（全库一屏看全）

想看全部文档的批注，用命令「打开批注索引」（命令面板搜 `Pick Me`）——右侧边栏出现一个索引：按源文档分组，每组列出文档名、条数，每条批注给出选区片段或 PDF 页码、提问数、锚点 id 与创建时间。

- 点文档名 → 打开源文档；点某一条 → 打开源文档并选中/跳到那条批注。键盘也能用：Tab 到条目上按回车。
- PDF 的批注会带一张框选区域的小图，一眼认得出是哪张；文本批注只给文字片段。
- 顶部有过滤框，按文档名、选区文字或锚点 id 过滤；右侧循环箭头重新读一遍。
- 锚点在原文里找不到的批注（你改过那段文字、或删掉了那对标签）不会删，也不会混在正常条目里：每组末尾收成一条「▸ 失效（N）」，点开才列出，并写明原因。处理办法是命令「重新绑定失效锚点」——它会列出当前文档里失效的批注，让你在原文重选一段把锚点挂回去。
- 单文档侧边栏（点正文高亮或命令「打开批注侧边栏」）的头部有「全部批注（索引）」入口，点它切到这个全局视图。
- 这个视图直接读批注文件，永远是最新的。插件还会在**自己的目录里**（隐藏）自动维护一份 `annotations-index.md` 汇总表，那是内部产物、没有设置项，看不看都行（要用 Dataview 就把插件目录加进扫描范围）。
- 只有插件自己的内部目录（`_assets` 区域截图、`_模板`）不算批注文件；文件名以 `_` 开头照常收录，所以 `_draft.md` 这类文档的批注也会出现在索引里。

## 正文（Markdown）里怎么问

选中一段文字，**右键**，菜单里一项：`Pick Me：提问或批注`。点完会在选区位置弹出面板，想问就问、不想问就是个批注。想用键盘就绑快捷键——命令面板里搜 `Pick Me` 绑定。

面板上的「带上下文」和「深度思考」勾选过就会记住，下次打开还是这个选择。

接口报 `Failed to fetch` 不用管：插件自己兜底——先试浏览器请求以保住流式，被跨域拦下就改用 Obsidian 通道重发。

面板内容可以自己滚：滚轮落在面板上只滚面板，滚到头也不会带着底下的文档一起动。

## 设置里两个跟模型有关的开关

**深度思考**（默认开）：开了先让模型推理再作答，质量更好、也更慢。思考内容有独立预算，**不占**「最大输出长度」——这个额度只管正文。想快就关掉，或在提问面板上按次取消勾选。

**界面语言**（默认 English）：设置面板与插件提示支持中英切换，切完命令名与各视图文案会立刻跟着变，不用重启。模板正文与批注文件里写的内容不翻译，那是你自己的笔记。

如果批注里出现「模型只输出了思考内容」：把「最大输出长度」调大（默认 4096）即可；批注里会写明这次是不是被截断。

## 设置项说明

设置面板里的每一项是什么、什么时候需要动它。分节顺序与面板一致。

### 通用

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 界面语言 | English | 设置面板、命令名、插件提示的语言。只影响插件自己的界面文字，不影响你的笔记内容。切完立刻生效，不用重启。 |

### 批注存放

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 批注目录 | `.obsidian/plugins/pickme/annotations` | 批注文件放哪。默认在插件目录里，好处是眼不见心不烦；代价是 Obsidian 不索引隐藏目录，批注搜不到、双链也链不上。改成库内目录（如 `60-批注`）后就能用 Dataview 查、能用双链跳。 |
| 迁移批注目录 | — | 改了上面的目录后点它，把已有批注按原镜像结构搬过去。**是搬不是复制**：逐个文件「写新的、删旧的」，不会两处各留一份；搬完旧目录会剩下空文件夹，留着还是删掉都不影响使用。不点就不会搬。 |
| 为没有批注的文档也建批注文件 | 关 | 打开后，每读一个文档都会生成一个空的批注文件。默认关，避免文件浏览器里全是空文件。 |

### 模板

模板就是提示词。内置只留 3 个最常用的（**解释／摘要／翻译**），其余按自己的需要加——模板目录里的每个 `.md` 就是一个模板，**文件名就是下拉里显示的名字**。

内置的 3 个都把「你的问题」写成可选段落：填了就带上去、没填就整段消失，不需要你自己去补占位符。

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 模板目录 | `.obsidian/plugins/pickme/templates` | 模板固定放在插件自己的隐藏目录里，**不用改**（这是只读的一行，只用来告诉你位置）。想看/改模板文件，点右边的「打开模板目录」在访达里打开。 |
| 恢复默认模板 | — | 把内置 3 个（解释／摘要／翻译）重新写进模板目录，已存在的不覆盖（你改过的措辞不会被冲掉）。删掉的、改坏了的，用这个找回来。 |
| 模板清单（每行一个开关 + 删除） | 全开 | 勾上就在提问面板的下拉里出现；取消勾选只是藏起来，文件不会被删。右侧垃圾桶 = 删掉这个模板文件（会先确认；内置的删了可以用「恢复默认模板」找回来）。 |
| 新建模板 | — | 在模板目录里建一个新模板文件，可用的变量都列在文件里。新建的模板排在清单最后（内置 3 个始终在最前）。 |

**模板怎么作用于提问**：面板下拉选「直接提问」时，送出去的是「你输入的问题 + 选区（+上下文）」；选了某个模板时，送出去的是**模板正文**，你输入的字填进模板里的 `{{提问}}` 占位。内置的 3 个都带这个占位符，所以「选着模板 + 顺便问一句」是有效的。

`{{选区}}` 这类变量为空时，它所在的那一行会被**整行去掉**——所以模板里可以放心写「另外回答这个问题：{{提问}}」这种可选段落。

**自定义模板**：在模板目录里新建任意 `.md`，正文写提示词，文件名就是模板名，保存后立刻出现在下拉里。正文里可以用这些变量：`{{选区}}`、`{{提问}}`、`{{上下文}}`、`{{笔记标题}}`、`{{源路径}}`、`{{页码}}`、`{{已有批注}}`。frontmatter 里能覆盖本次运行的参数：

```yaml
pickme_model: qwen/qwen3.8-flash-next   # 这个模板用哪个模型，留空用默认模型
pickme_temperature: 0.7                  # 覆盖默认温度
pickme_include_note: false               # 是否把整篇笔记也送进去
pickme_vision: true                      # PDF 区域截图是否送图
pickme_context: false                    # 是否附带选区前后文
```

### 模型通道

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 接口地址 | `https://api.openai.com/v1` | OpenAI 兼容接口的 base url。中转站、内网网关都填这里。 |
| 默认模型 | `gpt-4o-mini` | 没在模板里指定模型、也没在面板里另选时，用这个。 |
| 温度 | 0.3 | 0 到 1，越小回答越稳越确定，越大越发散。问答建议 0.2~0.4。 |
| 流式输出 | 开 | 一个字一个字地出；关掉就等全部生成完再显示。 |
| 深度思考 | 开 | 让模型先推理再作答，质量更好也更慢。思考有独立预算，**不占**「最大输出长度」。 |
| 侧边栏可选模型 | 空 | 每行一个模型名（或逗号分隔），面板的下拉就会列出它们，方便临时换模型。留空只能用默认模型。 |
| 视觉模型 | 空 | PDF 区域截图走这个模型。留空表示跟默认模型是一个（那它得支持图片）。 |
| 允许图片输入 | 开 | 关掉后 PDF 框选只用文字层里取到的文字提问，不送截图，适合用纯文本模型时。 |
| 最大输出长度 | 4096 | 单次回答的 token 上限，**只管正文**，思考另算。推理型模型答到一半被截断多半是这个值太小。 |
| 请求超时（秒） | 120 | 超时就中止，已经生成的部分会保留在批注里。0 表示不限制。 |
| 测试连接 | — | 按上面的地址与密钥发一个最小请求，确认能不能通。 |

### 选区与上下文

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 选区上限（字符） | 2000 | 一次最多送多少字。超了会截断并加一行提示。PDF 框选取到的文字也算在这里。 |
| 上下文上限（字符） | 1500 | 「带上下文」时，往选区前后各取多少字一起送。给模型一点前后文，回答通常更准。 |
| 默认附带上下文 | 开 | 面板打开时「带上下文」是否默认勾上。 |

### 交互

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 在页面内提问 | 开 | 提问面板直接开在页面上，不必打开侧边栏。关掉就回到「提问在侧边栏」的老方式。 |
| 添加批注后自动打开提问面板 | 开 | 框选完顺手把面板弹出来。荧光笔不受这个开关影响——它只做高亮。关掉则只留标记，想提问再点它。 |

### PDF

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 用自带查看器打开 PDF | 开 | PDF 由 Pick Me 的查看器打开，才能框选。关掉就用 Obsidian 内置查看器（那样没法框选）。 |
| 显示批注高亮 | 开 | 页面上画出已有批注的框。关掉就是原始 PDF 的样子；工具栏最右边也有个按钮随时切。 |
| 保存区域截图 | 开 | 框选时把这块区域裁成 PNG，存在这条批注旁边（`_assets/` 下），提问时当图片一起送。**删批注时一起删**，不会越积越多。不需要图文问答就关掉，能省下这些图占的空间。 |
| 截图最大边长（像素） | 1200 | 截图等比缩到这个边长再存。它是给**模型看的图**：图越大越清晰、但 token 也越贵；1200 大致是「表格数字还能看清、又不至于太贵」的位置。0 表示不缩放。 |
| PDF 默认缩放 | 1.2 | 打开 PDF 时的初始缩放，1 是原始大小。 |

### 锚点与外观

| 设置项 | 默认 | 直白解释 |
| --- | --- | --- |
| 锚点标签名 | `pickme` | 正文里那对标记用的标签名。一般不用改；改了以后老批注要重新绑定才认。 |
| 视觉标记样式 | 底色 | 正文里批注范围怎么标：底色、下划线、还是左边框。 |
| 高亮颜色 | `#98cbed` | 上面的颜色。 |

## 验收标准怎么自测

| # | 验收点 | 怎么测 |
| --- | --- | --- |
| 1 | 原文只多一对锚点标签 | 加一条批注后用 `git diff` 看源文档，只有两处 `<pickme id="…"></pickme>` |
| 2 | 批注文件字段齐全 | 看配置目录下的镜像路径，frontmatter 有源路径与批注条数 |
| 3 | 导出 PDF 不含标签 | 用 Enhancing Export 导出该文档，正文不出现 pickme 字样 |
| 4 | PDF 高亮随缩放对齐 | 框选后在 50%／100%／200% 三档缩放间切换，框与原文对齐 |
| 5 | 流式、模板、模型切换 | 提问时逐字出现；换模板换模型后回答风格与模型随之变化 |
| 6 | 目录迁移 | 改批注目录 → 弹窗确认迁移 → 文件搬走、源路径字段正确、索引能聚合 |
| 7 | 删除同步 | 删一条批注：条目、区域截图、原文里的那对标签一起消失，选区内文字保留 |
| 8 | 三类错误有提示 | 接口地址写错／密钥无效／断网，都弹明确提示且不留半截条目 |
| 9 | 单条失效不牵连 | 手动删掉原文里的一个标签 → 只有该条显示失效，其余正常，「重新绑定」可修 |
| 10 | 按 id 跳转 | 「跳转到锚点」输入 id 直接定位，不依赖顺序解析 |

## 已知限制

- pdf.js 的 CMap 与标准字体已内联进 `main.js`（构建时由 `npm run assets` 生成，整体 gzip 打包、用到时惰性解压一次），代价是 `main.js` 约 3.8 MB。
- 不支持移动端：自带 pdf.js 查看器与区域截图都依赖桌面端能力。
- 窗口被最小化或被其他窗口完全遮住时，Chromium 会停掉 requestAnimationFrame，pdf.js 的渲染也跟着停（页面暂时画不出来）。切回前台会自动补画；若状态栏提示渲染超时，点它旁边的「重试」即可。
- 连续滚动下页面尺寸在打开时就全部量好，所以首次打开很长的 PDF（上千页）会多花一点准备时间；滚动条长度从第一帧起就是准的。
- 锚点标签在源码模式下可见（`<pickme id="xxxxxx"></pickme>`），编辑视图与阅读视图里都不可见。
- 视觉标记靠阅读视图后处理器与 CodeMirror 装饰器，若与其他插件抢同一段文本的装饰，以 Obsidian 的渲染结果为准。

仓库里只放插件本体与构建脚本；设计与验收细节文档留在开发库内，不随仓库发布。
